System Overview

This AI-based Predictive Maintenance System monitors and analyzes ship machinery performance using advanced machine learning and data analytics techniques. It processes real-time and simulated sensor data to detect anomalies, generate health scores, predict potential failures, and identify root causes in advance.

Engine Module

The engine module continuously monitors parameters such as engine speed (RPM), temperature, pressure, and load conditions. It detects issues like overheating, abnormal combustion, and performance degradation, enabling early fault prediction and efficient engine operation.

Gearbox Module

The gearbox module analyzes input shaft speed, output shaft speed, torque, vibration, temperature, and gear ratio. It helps detect faults such as gear wear, bearing failure, misalignment, lubrication issues, and overheating. Machine learning models are used to identify inefficiencies and predict failures based on variations in mechanical behavior.

Waterjet Propeller Module

The waterjet propulsion module monitors pump pressure, flow rate, jet velocity, temperature, and vibration. It identifies issues like cavitation, intake blockage, pressure loss, and pump inefficiency, ensuring optimal propulsion performance.

The system provides real-time monitoring, intelligent alerts, and maintenance recommendations through an intuitive interface. By enabling proactive, data-driven maintenance, it improves reliability, reduces downtime, and enhances overall system efficiency.
